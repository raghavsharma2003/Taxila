# Placement item bank (RS-6, 2026-10-04)

Classes 3-8: maths (3-8), EVS (3-5), science (6-8). 12 items per band; bands early / mid / late of class C
(GE anchors C-0.8, C-0.5, C-0.2) plus a `foundation` band (C-1.5) in class 3. Every item is code-gradable: `numeric`
(one number, optional unit) or `mcq` (4 options, one correct, distractors from real misconceptions).

Fields: `ge` (band anchor, used by the CAT), `geRated` + `geRaters` (two v2 raters), `anchorMismatch` (both raters > 1
class from the anchor: excluded), `verified` (blind solver, other family), `adjudicated` (5 solver disagreements where the
key was checked and correct; marked as a model's adjudication, not a human's), `topicRef` (curriculum topic).

Read by `server/placement/bank.js` (`usable()` decides). Generated by `evals/content-level-v2/placement/gen.mjs`.
