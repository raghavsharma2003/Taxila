## Gotchas

- **Never source .env.local in bash.** An unquoted `&` in a URL line backgrounds the assignment and echoes the value.
  This happened once on 2026-10-22: one test-branch database URL was printed into my own tool output only. Main passed
  rotation to the owner. Load env with `node --env-file` only.
- **Use only TEST_DATABASE_URL, read-only.** `TAXILA_DB=test` makes db.js prefer CONDUCTOR_TEST_DATABASE_URL, which is
  not ours. The scripts clear TAXILA_DB and delete that variable first.
- **Context inbox.**
  - Never edit a file under `context/inbox/merged/`. Main moves inbox files there when merging, and a later merge of
    yours will apply your edits onto the merged file. If that happens, restore the merged file to main's version and put
    the nodes in a new inbox file.
  - Write-ups go in the inbox file's `md` section (`{nodes, edges, md: {measurements|decisions|rejected}}`); merge-inbox
    appends them. Do not edit measurements.md directly; it conflicts with main at the end of the file.
  - `node scripts/context.mjs --check` must pass.
- **Gate under the CI env.** Without it the Neon tests try real databases. The baseline is 5 env failures plus 1 todo;
  anything else is yours. A full run is about 20 minutes. Run it in the background with fresh output files, and never
  two at once on the same files.
- **Kill processes by PID, never with `pkill -f`.** A broad pattern once killed my own shell.
- **Tests must fail on the base.** Check by stashing the source and running the new test. An untracked test file stays
  in place, so it then runs against the base code.
- **The Vercel bot shows "Error" on PR #24.** The Vercel project is paused (Azure-only directive). Not ours.
- **Shapes are notes, not lines.** Sentence-shaped prompt text gets recited. Rules that must fire go last. Guards repair
  in code after one rewrite: the rewrite hint, then a strip, then keepOr ending on the pinned question.
- **The owner-4 contract.** An example, story, slower or another-way request during teaching is a `reteach` that does
  not advance teachIdx (tests/p5-interaction-director). The kit-example change keeps that kind.
- **Commits.** No model identifiers in commits or PRs, and no child words in commits. Quote a sha only after its push
  returns. Reports to main go by `send_message` to session_0135KCpT8GA8E1uzNPiw2Hw3, with shas and numbers.
