## Gotchas

- **Gates:** `CI=1 DATABASE_URL= DATABASE_URL_DIRECT= TAXILA_DB= npx tsc -b && npx vite build && npm test && node scripts/check-prompt-budget.mjs`
  (~25 min). Tests read files live: never edit the tree while a gate runs. One TODO (RCA-4b) is expected.
- **Database:** `.env.local` `DATABASE_URL` is 4B's own Neon branch (TEST, `TAXILA_DB=test`). Production is off-limits.
  `scripts/migrate.mjs` splits on `;` (no `DO $$` blocks); re-applying an edited migration on your own branch means
  deleting its `schema_migrations` row first.
- **D5 has no partials:** words said over her line always land after her line; the device sees a child's onset LATE under
  her echo while Voice Live's VAD opens the item at the true start (`CARRY_PRE_MS = 1200` in fanin.js).
- **Skeletons are lossy:** `skeleton("नहीं") = "n"` = her "हैं" / "ना" / "हाँ". Use `echoKey`, and keep cross-script
  matching (her Roman line comes back from the ear in Devanagari): test any echo change on BOTH floors
  (`negation-echo.mjs`).
- **Empty turns:** an empty D5 commit is silence to the server unless it carries `duplex.unheard`; the hold offer must stay
  wordless (`"रुको"` as words reads as a stop).
- **Trace in replays:** `node --import <preload that sets globalThis.__taxilaTrace = { emit, full }> arms-d5.mjs --replay …`;
  arms-d5's main block only runs as the entry point.
- **Process hygiene:** never `pkill -f` (it matched and killed the shell); kill by pid. Background waiters time out
  (30–60 min); re-arm.
- **Branch hygiene:** merge `int/*` into the branch (never rebase pushed history); main allots migration numbers; inbox
  entries go in a NEW `context/inbox/*.json` with md write-ups (main asked, 10-21); commit messages carry the
  Co-Authored-By / Claude-Session lines, never a model id; no child words in commits.
- **Owner directives in force:** Azure-only AI; STOP on Azure spend (10-24) until the owner lifts it — no model, realtime,
  speech or TTS calls; the safety files `server/director/safety.js`, `server/compiler/floor.js`,
  `src/lesson/safetyStrings.ts` are frozen; `state.js` safety changes go through main's safety review.
