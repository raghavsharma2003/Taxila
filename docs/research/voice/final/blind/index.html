Teacher voice, final round: which one should be her voice?

There are three short lessons. In each one the same three voices say exactly the same words, which are printed above the voices so you can read along. The voices keep the same name in every lesson (for example, Voice ABC is the same voice each time), but their order changes. Listen to each voice, then score how much it sounds like a real teacher talking to me, tick anything that went wrong, and write a note if something stands out. Notes matter most: write what you hear, in any language. The score unlocks once you have heard most of a voice. At the end, pick the one voice she should have. Use headphones. Ratings save automatically under your name.

1 = clearly a machine reading · 3 = could pass, but something is off · 5 = a real teacher talking to me

Each person types their own name before starting. Several people can use the same account or phone: ratings are kept separately under each name.
