# Model scout: every live option on Azure Foundry and AWS, by Taxila use case (2026-10-04)

**Status.** This is a scout, not a router change. It lists what exists, how it is billed, and where it runs. Where
possible it also gives a measured first number and ranks the candidates for each use case.
`MODEL-ROUTER.md` stays authoritative until a bench promotes a candidate.

**Scope rule (owner directive 2026-10-04).** A candidate is eligible only if it is paid by one of two sources:
- the Azure grant, on a Direct-from-Azure meter;
- the AWS credits: USD 1,000 Activate Founders plus USD 100 Free Tier, account 780899467240.

Users are India-only, so placement is preferred in Azure `southindia` and AWS `ap-south-1` (Mumbai).

**Not duplicated.** The model-refresh bench (`evals/model-refresh-2026-10-04/**`) already covers these, so this scout
only cites them:
- gpt-6-luna, gpt-6-sol, gpt-6.1-sol, gpt-6-astra
- DeepSeek V4/V4.1 (incl. V4-Flash-0731), Kimi K2.6 and K2.7-Code
- mistral-medium-3-5, mistral-ocr-4-0
- MAI-Transcribe-2 (batch and streaming), gpt-transcribe, gpt-realtime-whisper
- gpt-image-2.5-flare and -sunburst, MAI-Image-2.6 (base)
- text-embedding-3-large, Cohere embed-v-4-0 and Embed-V5-Pro
- MAI-Voice-2.1 and DragonHD (smoke only)
- model-as-orchestrator

Its billing table (`setup/CANDIDATES.md`) is reused as is.

**Evidence tags:** [M] measured here · [M-ref] measured by the refresh bench or earlier (cited) · [V] vendor API, price API
or doc · [U] untested judgement.

All raw data is in `evals/model-refresh-2026-10-04/scout/` (results/ and the scripts that produced it).

## 0. Headline findings

1. **AWS Bedrock cannot be called yet.** Every `Converse` call failed, in two different ways:
   - ap-south-1: *"Your account is currently being verified"*.
   - us-east-1: `ThrottlingException: Too many tokens per day`.
   - Service Quotas show **0 tokens/day, not adjustable**, for Nova, Kimi K3 and others in both regions [M, 2026-10-04].

   The control plane works: listing, availability and pricing all answered. Everything below about Bedrock *models*
   is therefore catalogue and price data only. **Owner action O-1** (§5) unblocks it.

   AWS speech services work today: Transcribe streaming and Polly were both called.
2. **Kimi K3 is reachable and credit-eligible on Bedrock in Mumbai.** On Azure it is blocked: its only meter is
   Fireworks, and the deploy fails with `SpecialFeatureOrQuotaIdRequired` (CANDIDATES.md). On Bedrock:
   - `global.moonshotai.kimi-k3` is listed for ap-south-1.
   - It needs no Marketplace agreement ("Agreement not supported for this model"), so AWS sells it first-party.
   - Price $3.30 / $16.50 per 1M tokens [V].

   The same holds for **grok-4.7**, which is newer than anything on Azure (Azure's newest is grok-4.6): $2.20 / $6.60 [V].
3. **gpt-live-1** is OpenAI's full-duplex voice API, released 2026-09-10.
   - It is listen-and-speak-at-once, with no rigid turn boundaries.
   - It is GA, on a Direct meter ("Live 1 Gl", **$3.00 per hour**).
   - Of our regions it is offered in **southindia** (and eastus2).
   - Nobody covers it. The deploy failed with `InsufficientQuota` (available capacity 0 RPM). This is **owner action O-2**.
4. **MAI-Image-2.6-Flash is the best image result in this repo so far, on a small n.** n = 2 runs × 3 prompts, same
   judge and rubric as `image-bench-2026-10-02.json`:
   - 18/18 criteria at 5 on 5 of 6 images; the one exception was artifacts 4.
   - All 10 plant labels were correct. I also checked one diagram by eye.
   - p50 16.7 s, about **$0.02 per image** [M].
   - Compared with gpt-image-2 (5/5, 37-47 s, $0.053) and FLUX.2-pro (6.2 s, $0.03, wrong labels) [M-ref].
   - It is Preview, southindia only.
   - MAI-Image-2.5-Pro is worse and 5x the price: one diagram had 4 labels pointing at the wrong part, 32-47 s,
     about $0.11 per image [M].
5. **Amazon Transcribe streaming hi-IN does not beat the incumbent.** Same 180-clip corpus as `stt-hinglish.md`:

   | arm | CER | numbers right | final text after speech end (p50) |
   |---|---|---|---|
   | Transcribe streaming hi-IN [M] | 0.086 | 67/96 | 2.10 s |
   | `taxila-live-transcribe` D4 [M-ref] | **0.026** | **92/96** | **1.32 s** |

   Transcribe en-IN is far worse: CER 0.277, numbers 23/96. **Rejected for live STT**; see the inbox entry.
6. **AWS Activate credits cover third-party Bedrock models, including the Marketplace-billed ones.** AWS Activate Terms
   §1.2 (last updated 2026-01-22) say Activate Credits *"may be applied to offset fees and charges for AWS Marketplace
   incurred for the use of third-party foundation models available on Amazon Bedrock … AWS Marketplace is an Eligible
   Service solely when incurring Bedrock 3P Model Spend"* [V].

   Two caveats:
   - The general AWS Promotional Credit terms §1 exclude AWS Marketplace. Whether the **USD 100 Free Tier credit**
     also covers Marketplace-billed models is not stated [U].
   - One re:Post thread reports Claude Opus 4.5 Marketplace charges *not* offset.

   So verify on the bill after the first day of use. Cost Explorer already shows credits offsetting usage in October:
   Usage $1.10, Credit −$1.10 (EC2 from scripts/gpu) [M].

## 2. AWS: what exists, what the credits pay for, where it runs

**Method.** All calls on 2026-10-04 with the IAM credentials from `.env.local` (account confirmed via STS):
- `bedrock:ListFoundationModels` and `ListInferenceProfiles` in ap-south-1 (84 models, 42 profiles) and us-east-1
  (120, 93) → `results/bedrock-list.json`
- `GetFoundationModelAvailability` and `ListFoundationModelAgreementOffers` → `results/bedrock-availability.json`
- AWS Price List API for ap-south-1 → `results/bedrock-prices-aps1.json`
- Service Quotas for Bedrock
- Cost Explorer grouped by RECORD_TYPE
- Polly `DescribeVoices` and `SynthesizeSpeech`
- Transcribe streaming

**Seller of record.** Two kinds of response tell them apart:
- `ListFoundationModelAgreementOffers` returns a Marketplace offer for **OpenAI (gpt-5.x / gpt-6.x), Anthropic,
  Cohere and Stability**. These need a Marketplace subscription, and they show as `agreementAvailability:
  NOT_AVAILABLE` today.
- For everything else it returns *"Agreement not supported for this model"*: Amazon Nova, Moonshot Kimi, xAI Grok,
  Z.AI GLM, MiniMax, Qwen, Mistral, DeepSeek, gpt-oss and gpt-oss-safeguard, Gemma, Voxtral, NVIDIA. AWS sells these
  first-party. Activate credits cover them under the general terms, and Marketplace-billed models under §1.2.

**India placement.** There are two ways to call a model from ap-south-1:
- `in.*` profiles **stay inside India** (ap-south-1 plus ap-south-2): `in.openai.gpt-5.6-luna`, `in.openai.gpt-5.6-terra`,
  `in.anthropic.claude-sonnet-5`, `in.anthropic.claude-opus-5`, `in.anthropic.claude-haiku-4-5`.
- `global.*` profiles start in ap-south-1 but may serve anywhere. Kimi K3, grok-4.6 and 4.7, Nova 2 Lite, gpt-6 and
  gpt-6.1 and the Claude 5.x models are only available this way.

On-demand in-region models: Nova Micro / Lite / Pro (via `apac.*`), DeepSeek V3.2, Qwen3 (235B, coder-480B, next-80B,
VL-235B), Mistral Large 3 and Voxtral, GLM-5, MiniMax M2.5, gpt-oss and safeguard, Gemma 3.
