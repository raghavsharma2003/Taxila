## Measured (per engine)

each played 2500 ms; a visible failure = page error, no ready in 6 s, blank stage, or failure-shaped chrome text.
Faults: transient (2 throwing frames → held on the last good frame), permanent (every frame throws → `engine_failed` → board), boot (create throws → board).
Run = the bot's recorded session (1024×640, ≤ 50 s): host-graded answers, engine/host verdict agreement, undersized labels, safe-zone hits.
Spec bench = taxila-fast-bg, JSON mode, n per archetype as shown; "strict raw" = the model's output passes the zod schema before any repair.
