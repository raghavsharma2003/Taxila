Reply-ready p50 is slower in 7 of 12 lessons, by up to about 0.8 s, because guard rewrites went from 10 to 14 per lesson.

## Root causes

1. **The guards detect but don't prevent.** "level", "underived", "invented" and "screen" fire on exactly the turns that then ship wrong.
2. **A guard's rewrite instruction causes the defect.** The screen rewrite says "say it in words".
3. **Prompt text is recited.** "no guilt", "carry on, short break, ya stop for today", and "tumne X kaha" ×7 per lesson. This breaks the inherited law: sentence-shaped prompt text gets recited.
4. **Teaching is improvised turn by turn**, not rendered from the kit:
   - no worked example is real;
   - the answer sits inside the question;
   - the lesson jumps between denominators;
   - "game:" and "kahani:" are labels stuck on the same quiz, which is OWNER-RESET #3 "quiz in costume".
5. **Steering cannot be real in the harness.** No board or game is picked, so "picture" requests get words.

## Decision (dc-r7-brain-structural-block)

Stop patching line by line. Brain's next block is structural:

| Item | Change |
|---|---|
| S1 | Guards enforce: regenerate once with the constraint, otherwise a code line. A test checks that no flagged line ships. |
| S2 | Worked examples are rendered by code from the kit. Questions are templated so the answer can't be inside them. |
| S3 | One live item at a time, and the arc follows the kit's skill order with bridges. |
| S4 | Steering is real: picture goes to Studio's board, game to the play family. The harness records what is on screen. |
| S5 | Sentence-shaped prompt text is removed (shapes, not lines). |
| S6 | A reply-model A/B: taxila-gpt6 vs taxila-fast on the Director lane. |

Reverse when a re-run after S1-S5 shows the same defects. That would point to the plan and wording architecture itself, not its enforcement.
