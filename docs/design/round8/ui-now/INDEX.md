# Taxila UI as it is today: screen capture index

Branch `int/r6` worktree `/home/user/taxila-int` (read-only; nothing edited, no `.env` read, no external API, no `tests/prod`). 179 screens x 2 viewports.
Viewports: `p360` = 360x740 @2x (mobile emulation, touch), `d1366` = 1366x768 @1x. Each screen has a full-page PNG `<stem>-<vp>.png`; when the page scrolls there is also a viewport-only shot named `<stem>-<vp>-vp.png`.
Caveat on full-page shots: fixed chrome (bottom tab bar, side rail, top bars) is painted once at its viewport position, so it appears mid-image on long pages; use the `-vp` shot for the true first view. `reducedMotion: reduce` was on for every capture.
Contact sheets: `contact-p360-1..5.png`, `contact-d1366-1..5.png` (ordered by file number, caption = file stem; each tile is the top of the full-page shot).

## How it was run
- `npx vite` dev server on 127.0.0.1:5173 from the worktree via a wrapper config in `ui-now-tools/vite.wrap.mjs` (same plugins, `cacheDir` moved to scratch so `node_modules/.vite` was not touched). Dev build, so `/dev/*` routes exist.
- Playwright (one chromium, sequential). `page.route('**/api/**')` answers every call from fixtures in `ui-now-tools/` (`lib.mjs` runner, `fx.mjs` + `fxchild.mjs` child/guardian fixtures, `b1`..`b6.mjs` scenario files). Unlisted `/api` calls get `404 {}` (only `face/config`, `trace/batch`, `parent/lock`, `duplex/config`, `tutors/greeting` were hit; nothing visibly depends on them).
- Simulated people: child "Riya", class 5 (class 8 for Ask, class 3 for the garden), Hinglish; second child "Kabir"; parent "Meena Sharma" (parent@example.com). Cookie `tx_in=1` marks a signed-in session; signed-out shots send no cookie and `/api/me` 401.
- Child fixtures derive from the repo's own `src/child/dev/app-shots.mjs`; parent reports are the REAL report pipeline (`server/reports/*`) run on `tests/fixtures/report-facts.mjs` (so report prose is real, and its topics are that fixture's, not Riya's).
- Lesson Desk screens use the repo's fixture harness `src/ui-v3/kaksha/dev/desk.html?fixture=<name>` (the real `Desk` + Kaksha skin fed `fixtureModel()` from `src/child/lesson/dev/DeskDev.tsx`), not the live `/c/:cid/lesson/:lid` runtime. Board-drawing states were re-shot with a 5 s wait because the board animates in.
- Games use the repo's play dev harness `src/play/dev/index.html` (real `PlayStage`, level built by the server's generator in-browser; `window.__play.solve()` acts dispatched for the "level end / doors" shots). 12 of 33 families shown, one mode each.

## Design system as found
**CSS approach:** plain global CSS (no Tailwind, no CSS Modules, no CSS-in-JS lib), class names per area, one big token layer of CSS custom properties. Inline `style={{}}` is used too: 153 occurrences in 58 `.tsx` files. 36 `.css` files, ~387 KB total.
**Token / theme files:** `src/styles/tokens.css` (classic/Wave-2 tokens, also read by `src/ui/*`), `src/ui-v3/tokens.css` (scoped `.v3`, mirrors `src/ui-v3/tokens.ts`; Night + Day themes), `src/ui-v3/kaksha/tokens.css` (the shipped child skin "Kaksha": `--k-*`), `src/ui-v3/kaksha/{kaksha,kit,futurist,nav,childshell}.css` (skin, kit, "volt"/"holo" looks), `src/onboarding/volt.css` + `onboarding-v2.css` + `src/styles/onboarding.css`, `src/styles/{base,ui,app,landing}.css`, `src/child/child.css`, `src/child/lesson/desk.css`, `src/parent/parent.css`, `src/studio/studio.css`, `src/play/play.css`, `src/avatar/avatar.css`, `src/ui-v3/scheduler.css`. Kaksha is the default child app for every account since release 11 (`src/ui-v3/kaksha/flag.ts`); `?ui=classic` on a device falls back to the classic skin (shots 51-52, 63, 64).
**Fonts (self-hosted, `public/fonts`, `src/ui-v3/fonts`; declared in `src/styles/fonts.css`, `src/ui-v3/tokens.css`, `src/ui-v3/kaksha/tokens.css`):** Space Grotesk (`--k-sans`, Kaksha), Geist Mono (`--k-mono`), Bricolage Grotesque (v3 headings), Atkinson Hyperlegible Next (`--font-ui`, classic UI), Literata and Andika (classic older/young titles/text), Mukta (Devanagari subset by unicode-range). Var names: `--font-ui/-title/-heading/-text/-deva`.
**Icons:** inline SVG, no icon library: `src/ui/Icon.tsx` (30 named icons, 24 dp grid, 2 px stroke, `currentColor`), `src/ui-v3/Icon.tsx`, `src/ui/icons/state.tsx` (ledger state shapes), `src/child/pictos.tsx`, `src/ui/Art.tsx` / `src/child/art.tsx`. Raster art in `public/assets/**`, `public/site/**`. Animation lib: `framer-motion` (dependency); `prefers-reduced-motion` has 23 `@media` blocks.
**Counts by grep over all 36 CSS files (literals as written, duplicates across files collapsed):**

- colours: 351 distinct hex literals, 97 distinct `rgb()/rgba()/hsl()/oklch()/color-mix()` expressions; 195 distinct custom-property names defined; 3,346 `var(--*)` uses.
